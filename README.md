# 🔥 SpiceBite Honeypot

A web based honeypot disguised as a modern restaurant platform for cybersecurity research, attack monitoring, and threat analysis.

---

## 🚀 Features

* Real-time threat monitoring
* Suspicious login detection
* File upload activity analysis
* Request and payload monitoring
* Admin analytics dashboard
* Attack logging and visualization
* Modern responsive UI

---

## 📁 Project Structure

```text
honeypot/
├── app.py
├── templates/
├── static/
├── uploads/
├── logs/
└── README.md
```

---

## 🛠️ Tech Stack

* Python
* Flask
* SQLite
* HTML/CSS
* JavaScript
* Bootstrap

---

## ⚙️ Installation

```bash
pip install flask
python app.py
```

Application runs locally at:

```text
http://localhost:5000
```

---

## 🌐 Core Modules

| Module                    | Description                           |
| ------------------------- | ------------------------------------- |
| Authentication Monitoring | Detects suspicious login activity     |
| Upload Monitoring         | Tracks unusual file uploads           |
| Search Monitoring         | Analyzes malicious payload attempts   |
| Threat Dashboard          | Displays attack analytics and logs    |
| Activity Logging          | Records monitored events for analysis |
